# Project Requirements (متطلبات المشروع)

## 1. ملخص المشروع (Summary)
**Pharma Supply Chain Intelligence** هو نظام Data Engineering يجمع بيانات سلاسل إمداد الأدوية (الأسعار، التوافر، المخزون)، وينظفها ويوحدها ويحللها عبر الزمن، بالإضافة إلى RAG Assistant للإجابة عن أسئلة المستندات التنظيمية وتنبيهات استدعاء الأدوية مع إظهار المصدر والصفحة.

> **تنبيه:** النظام تحليلي ولدعم القرار، وليس نظاماً طبياً لتشخيص المرضى أو اقتراح بدائل علاجية.

---

## 2. نطاق المشروع (Scope)

### داخل الـ MVP (In-Scope)
- Ingestion من مصادر عامة أو ملفات محددة (CSV / JSON / PDF).
- Airflow DAG لتشغيل الـ Ingestion والـ Processing مع Retries و Logging.
- تنظيم البيانات بطبقات Bronze / Silver / Gold باستخدام Delta Lake + Parquet.
- تنظيف البيانات وفحوصات جودة البيانات (Data Quality Checks) وعزل السجلات غير الصالحة.
- تحليلات SQL للأسعار وتوافر المنتجات عبر الزمن.
- RAG إلزامي لمجموعة محددة من المستندات العامة مع استرجاع المصادر (Citations).
- واجهة بسيطة بـ Streamlit و FastAPI.

### خارج الـ MVP (Out-of-Scope)
- تقديم نصائح طبية أو اقتراح بدائل علاجية.
- التعامل المباشر مع نقل أو تخزين أو بيع الأدوية.
- Realtime streaming معقد أو distributed architecture ضخمة.
- Multi-agent systems متقدمة.
- OCR كامل لكل الملفات (الاعتماد الأساسي على استخراج النص الرقمي).

---

## 3. المتطلبات الوظيفية (Functional Requirements)
1. قراءة البيانات من مصادر موثقة أو ملفات تجريبية محددة.
2. تسجيل وقت التشغيل والنتائج والأخطاء لكل Pipeline Run.
3. حفظ البيانات الخام في Bronze مع الـ Metadata.
4. تطبيق الـ Cleaning والـ Standardization وفحوصات الجودة ونقل المرفوض للـ Quarantine.
5. توفير جداول Gold مناسبة للإجابة على أسئلة الأسعار والتوافر.
6. مسار RAG يستخرج من المستندات ويعرض مقتطفاً ومصدراً ورقم الصفحة.
7. عند غياب المعلومة، يعترف الـ RAG بعدم كفاية البيانات بدل التخمين.
8. واجهة تعرض التحليلات الأساسية ونتائج الـ RAG مع تمييز البيانات الحقيقية عن التجريبية.

---

## 4. المتطلبات غير الوظيفية (Non-Functional Requirements)
- **Reliability:** تسجيل الفشل في الـ Logs بوضوح وعدم تسجيل الفشل كنجاح.
- **Data Quality:** قواعد جودة قابلة لإعادة التشغيل.
- **Traceability:** إمكانية تتبع أي نتيجة تحليل إلى مصدرها وتاريخ تحميلها.
- **Reproducibility:** خطوات تشغيل واضحة في README.
- **Security:** منع رفع أي API Keys أو Secrets على GitHub واستخدام `.env`.
- **Responsible AI:** منع توليد إرشادات علاجية أو اختراع مصادر وهمية.
